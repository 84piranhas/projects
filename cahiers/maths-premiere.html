Algèbre

Second degré

Trinômes, discriminant, signe : la boîte à outils pour résoudre et étudier ax² + bx + c.

À retenir

Forme développée
f(x) = ax² + bx + c (a ≠ 0)
Discriminant
Δ = b² − 4ac
Si Δ > 0
deux racines x1 = −b − √Δ2a et x2 = −b + √Δ2a
Si Δ = 0
une racine double x0 = −b2a
Si Δ < 0
aucune racine réelle : f garde le signe de a
Forme canonique
f(x) = a(x − α)² + β avec α = −b2a et β = f(α)
Signe si Δ > 0
signe de a à l’extérieur des racines, signe de −a entre les racines
Somme et produit
x1 + x2 = −ba et x1·x2 = ca

MéthodePour résoudre une inéquation du second degré : calcule Δ, trouve les racines, dessine l’allure de la parabole (a > 0 : bras vers le haut), puis lis le signe sur le dessin.

Quiz

Question 1

Combien de racines réelles a 2x² − 4x + 5 ?

Réponse A. Δ = (−4)² − 4×2×5 = 16 − 40 = −24 < 0 : pas de racine réelle.

Question 2

Quelles sont les racines de x² − 5x + 6 ?

Réponse B. Somme = 5 et produit = 6, donc les racines sont 2 et 3. (Δ = 25 − 24 = 1.)

Question 3

Quelle est la forme canonique de x² − 6x + 1 ?

Réponse C. α = 3 et β = f(3) = 9 − 18 + 1 = −8. Donc f(x) = (x − 3)² − 8.

Exercice

Résoudre dans ℝ l’inéquation 2x² − x − 3 ≥ 0.

Voir la correction

Δ = (−1)² − 4×2×(−3) = 1 + 24 = 25, donc √Δ = 5. Racines : x1 = (1 − 5)/4 = −1 et x2 = (1 + 5)/4 = 3/2. Comme a = 2 > 0, le trinôme est positif à l’extérieur des racines. Ensemble des solutions : S = ]−∞ ; −1] ∪ [3/2 ; +∞[.

Suites

Suites arithmétiques et géométriques : formules explicites, sommes et sens de variation.

À retenir

Suite arithmétique
un+1 = un + r ⇒ un = u0 + n·r
Somme arithmétique
u0 + … + un = (n + 1) × u0 + un2
Suite géométrique
un+1 = q·un ⇒ un = u0·qn
Somme géométrique (q ≠ 1)
1 + q + … + qn = 1 − qn+11 − q
Sens de variation
étudier le signe de un+1 − un. Pour une suite géométrique avec u0 > 0 : croissante si q > 1, décroissante si 0 < q < 1.

MéthodePour reconnaître une suite géométrique, calcule le quotient un+1 / un : s’il est constant, c’est la raison q. Pour une suite arithmétique, calcule la différence un+1 − un.

Quiz

Question 1

Suite arithmétique de premier terme u0 = 5 et de raison 3. Que vaut u10 ?

Réponse B. u10 = 5 + 10×3 = 35.

Question 2

Suite géométrique avec u0 = 2 et q = 3. Que vaut u4 ?

Réponse A. u4 = 2×34 = 2×81 = 162.

Question 3

Que vaut 1 + 2 + 4 + … + 29 ?

Réponse C. Somme géométrique de raison 2 : (1 − 210)/(1 − 2) = 210 − 1 = 1023.

Exercice

Un capital de 1 000 € est placé à 5 % par an, intérêts composés. On note un le capital après n années. 1) Quelle est la nature de la suite (un) ? Donne un en fonction de n. 2) À partir de quelle année le capital dépasse-t-il 1 500 € ?

Voir la correction

1) Chaque année, le capital est multiplié par 1,05 : un+1 = 1,05·un. La suite est géométrique de raison 1,05 et de premier terme u0 = 1 000, donc un = 1 000 × 1,05n. 2) À la calculatrice : u8 ≈ 1 477,46 < 1 500 et u9 ≈ 1 551,33 > 1 500. La suite est croissante (q > 1), donc le capital dépasse 1 500 € dès la 9e année.

Dérivation

Nombre dérivé, tangente, règles de calcul et tableau de variations.

À retenir

Nombre dérivé
f′(a) = limh→0 f(a + h) − f(a)h
Tangente en a
y = f′(a)(x − a) + f(a)
Dérivées usuelles
(k)′ = 0 ; (x)′ = 1 ; (xn)′ = n·xn−1 ; (1x)′ = −1x² ; (√x)′ = 12√x
Opérations
(u + v)′ = u′ + v′ ; (ku)′ = k·u′ ; (uv)′ = u′v + uv′ ; (uv)′ = u′v − uv′v²
Variations
f′ ≥ 0 sur I ⇒ f croissante sur I ; f′ ≤ 0 sur I ⇒ f décroissante sur I
Extremum
si f′ s’annule en changeant de signe en a, f admet un extremum local en a

MéthodePour dresser un tableau de variations : calcule f′, factorise-la, étudie son signe, déduis-en le sens de variation de f, puis calcule les valeurs aux points clés.

Quiz

Question 1

Quelle est la dérivée de f(x) = 3x² − 5x + 1 ?

Réponse B. (3x²)′ = 6x, (−5x)′ = −5 et (1)′ = 0.

Question 2

Quelle est la dérivée de f(x) = (x + 1)(2x − 3) ?

Réponse C. (uv)′ = u′v + uv′ = 1×(2x − 3) + (x + 1)×2 = 4x − 1. On retrouve le même résultat en développant : 2x² − x − 3.

Question 3

Quelle est l’équation de la tangente à la courbe de f(x) = x² au point d’abscisse 2 ?

Réponse A. f(2) = 4 et f′(2) = 4, donc y = 4(x − 2) + 4 = 4x − 4.

Exercice

Soit f(x) = x³ − 3x² + 1 sur ℝ. Étudier les variations de f.

Voir la correction

f′(x) = 3x² − 6x = 3x(x − 2). C’est un trinôme de racines 0 et 2, avec 3 > 0 : f′ est positive sur ]−∞ ; 0[ et sur ]2 ; +∞[, négative sur ]0 ; 2[. Donc f est croissante sur ]−∞ ; 0], décroissante sur [0 ; 2], puis croissante sur [2 ; +∞[. Extremums locaux : f(0) = 1 (maximum) et f(2) = 8 − 12 + 1 = −3 (minimum).

Analyse

Exponentielle

La fonction qui est sa propre dérivée, ses règles de calcul et son signe.

À retenir

Définition
exp est l’unique fonction dérivable sur ℝ telle que f′ = f et f(0) = 1. On note exp(x) = ex.
Signe et variations
ex > 0 pour tout réel x ; exp est strictement croissante sur ℝ.
Règles de calcul
ea+b = ea·eb ; e−a = 1ea ; (ea)n = ena
Valeurs
e⁰ = 1 ; e¹ = e ≈ 2,718
Dérivée
(eu)′ = u′·eu ; en particulier (ekx)′ = k·ekx
Équations et inéquations
ea = eb ⇔ a = b ; ea < eb ⇔ a < b

MéthodePour étudier une fonction du type (ax + b)ex : dérive avec la formule du produit, factorise par ex, puis utilise ex > 0. Le signe de f′ est celui du facteur qui reste.

Quiz

Question 1

Simplifier e3 × e−5.

Réponse B. e3 × e−5 = e3 + (−5) = e−2.

Question 2

Quelle est la dérivée de f(x) = e2x+1 ?

Réponse B. (eu)′ = u′·eu avec u = 2x + 1 et u′ = 2.

Question 3

Résoudre e2x = ex+3.

Réponse A. e2x = ex+3 ⇔ 2x = x + 3 ⇔ x = 3.

Exercice

Soit f(x) = (x − 1)ex sur ℝ. Étudier les variations de f.

Voir la correction

f = uv avec u = x − 1 et v = ex. Alors f′(x) = 1×ex + (x − 1)ex = x·ex. Comme ex > 0, f′(x) a le signe de x. Donc f est décroissante sur ]−∞ ; 0] et croissante sur [0 ; +∞[. Son minimum est f(0) = −1.

Trigonométrie

Radians, cercle trigonométrique, valeurs remarquables et équations.

À retenir

Conversion
π rad = 180° ; 30° = π/6 ; 45° = π/4 ; 60° = π/3 ; 90° = π/2
Valeurs remarquables
x0π/6π/4π/3π/2
cos x1√32√22120
sin x012√22√321
Relation fondamentale
cos²x + sin²x = 1
Symétries
cos(−x) = cos x ; sin(−x) = −sin x ; cos(π − x) = −cos x ; sin(π − x) = sin x
Périodicité
cos(x + 2π) = cos x ; sin(x + 2π) = sin x
Dérivées
cos′ = −sin ; sin′ = cos
Équations
cos x = cos a ⇔ x = a + 2kπ ou x = −a + 2kπ ; sin x = sin a ⇔ x = a + 2kπ ou x = π − a + 2kπ (k ∈ ℤ)

MéthodePour une équation trigonométrique, ramène-toi à cos x = cos a ou sin x = sin a avec une valeur remarquable. Écris toutes les solutions modulo 2π, puis garde celles de l’intervalle demandé.

Quiz

Question 1

120° en radians, ça fait combien ?

Réponse B. 120° = 120 × π/180 = 2π/3.

Question 2

Que vaut sin(π/3) ?

Réponse B. C’est une valeur remarquable : sin(π/3) = √3/2 et cos(π/3) = 1/2.

Question 3

On sait que cos x = 3/5 avec x ∈ [0 ; π]. Que vaut sin x ?

Réponse C. sin²x = 1 − 9/25 = 16/25. Sur [0 ; π], sin x ≥ 0, donc sin x = 4/5.

Exercice

Résoudre 2cos x − 1 = 0 sur ]−π ; π].

Voir la correction

L’équation équivaut à cos x = 1/2 = cos(π/3). Donc x = π/3 + 2kπ ou x = −π/3 + 2kπ. Dans ]−π ; π], on garde k = 0 : S = {−π/3 ; π/3}.

Géométrie

Produit scalaire

Orthogonalité, longueurs, angles, droites et cercles dans un repère orthonormé.

À retenir

Définition
u·v = ‖u‖ × ‖v‖ × cos(u, v)
En coordonnées
u(x ; y) et v(x′ ; y′) : u·v = xx′ + yy′
Orthogonalité
u·v = 0 ⇔ u et v sont orthogonaux
Norme
‖u‖² = u·u = x² + y²
Développement
‖u + v‖² = ‖u‖² + 2 u·v + ‖v‖²
Al-Kashi
BC² = AB² + AC² − 2·AB·AC·cos Â
Cercle
centre Ω(a ; b) et rayon r : (x − a)² + (y − b)² = r²
Droite
de vecteur normal n(a ; b) : ax + by + c = 0

MéthodePour montrer que deux droites sont perpendiculaires, calcule le produit scalaire de leurs vecteurs directeurs : s’il est nul, elles le sont. Pour un cercle de diamètre [AB], un point M appartient au cercle ⇔ MA·MB = 0.

Quiz

Question 1

u(2 ; 3) et v(4 ; −1). Que vaut u·v ?

Réponse A. 2×4 + 3×(−1) = 8 − 3 = 5.

Question 2

Pour quelle valeur de k les vecteurs u(3 ; k) et v(2 ; 6) sont-ils orthogonaux ?

Réponse B. 3×2 + k×6 = 0 ⇔ 6 + 6k = 0 ⇔ k = −1.

Question 3

Dans le triangle ABC : AB = 5, AC = 8 et l’angle Â = 60°. Que vaut BC ?

Réponse A. BC² = 25 + 64 − 2×5×8×cos 60° = 89 − 40 = 49, donc BC = 7.

Exercice

Dans un repère orthonormé, A(1 ; 2) et B(5 ; 4). Déterminer l’équation du cercle de diamètre [AB].

Voir la correction

Le centre est le milieu de [AB] : Ω(3 ; 3). Le rayon vérifie AB = √(4² + 2²) = √20, donc r = √20 / 2 et r² = 5. Équation : (x − 3)² + (y − 3)² = 5. Vérification avec le produit scalaire : MA·MB = (1 − x)(5 − x) + (2 − y)(4 − y) = x² − 6x + y² − 6y + 13, qui s’annule exactement quand (x − 3)² + (y − 3)² = 5.

Probabilités

Probabilités conditionnelles

Arbres pondérés, formule des probabilités totales et indépendance.

À retenir

Probabilité conditionnelle
PA(B) = P(A ∩ B)P(A) (P(A) ≠ 0)
Formule des produits
P(A ∩ B) = P(A) × PA(B)
Probabilités totales
P(B) = P(A ∩ B) + P(A ∩ B) = P(A)·PA(B) + P(A)·PA(B)
Arbre pondéré
la somme des probabilités des branches issues d’un même nœud vaut 1 ; on multiplie le long d’un chemin, on additionne les chemins qui mènent à l’événement.
Indépendance
A et B indépendants ⇔ P(A ∩ B) = P(A) × P(B) ⇔ PA(B) = P(B)

MéthodeDevant un énoncé : nomme les événements, dessine l’arbre, place les probabilités données, puis complète. Pour renverser un conditionnement, utilise PB(A) = P(A ∩ B) / P(B).

Quiz

Question 1

P(A) = 0,4 et PA(B) = 0,5. Que vaut P(A ∩ B) ?

Réponse B. P(A ∩ B) = P(A) × PA(B) = 0,4 × 0,5 = 0,2.

Question 2

Une urne contient 3 boules rouges et 2 boules bleues. On tire deux boules sans remise. Quelle est la probabilité d’obtenir deux boules rouges ?

Réponse A. 3/5 × 2/4 = 6/20 = 3/10. (9/25 correspondrait à un tirage avec remise.)

Question 3

P(A) = 0,3 ; P(B) = 0,4 et P(A ∩ B) = 0,12. A et B sont-ils indépendants ?

Réponse A. P(A) × P(B) = 0,3 × 0,4 = 0,12 = P(A ∩ B) : les événements sont indépendants.

Exercice

Une maladie touche 2 % d’une population. Un test est positif dans 95 % des cas chez un malade et dans 10 % des cas chez une personne saine. On note M « la personne est malade » et T « le test est positif ». 1) Calculer P(T). 2) Calculer PT(M) et interpréter.

Voir la correction

1) Probabilités totales : P(T) = P(M)×PM(T) + P(M)×PM(T) = 0,02×0,95 + 0,98×0,10 = 0,019 + 0,098 = 0,117. 2) PT(M) = P(M ∩ T) / P(T) = 0,019 / 0,117 ≈ 0,162. Même avec un test positif, la probabilité d’être malade n’est que d’environ 16 %.

Variables aléatoires

Loi, espérance, variance et loi binomiale.

À retenir

Loi de X
valeurs xi et probabilités pi = P(X = xi), avec Σ pi = 1
Espérance
E(X) = Σ pi·xi
Variance, écart type
V(X) = Σ pi(xi − E(X))² ; σ(X) = √V(X)
Transformation affine
E(aX + b) = a·E(X) + b ; V(aX + b) = a²·V(X)
Loi binomiale B(n ; p)
P(X = k) = (nk) pk(1 − p)n−k ; E(X) = np ; V(X) = np(1 − p)
Coefficients binomiaux
(n0) = 1 ; (n1) = n ; (nk) = (nn − k) ; triangle de Pascal pour les petites valeurs de n

MéthodePour reconnaître une loi binomiale : on répète n fois la même expérience, de façon indépendante, avec deux issues (succès de probabilité p ou échec). X compte le nombre de succès.

Quiz

Question 1

X prend les valeurs 0, 1 et 2 avec les probabilités 0,5 ; 0,3 et 0,2. Que vaut E(X) ?

Réponse A. E(X) = 0×0,5 + 1×0,3 + 2×0,2 = 0,3 + 0,4 = 0,7.

Question 2

X suit la loi binomiale B(10 ; 0,3). Que vaut E(X) ?

Réponse B. E(X) = np = 10 × 0,3 = 3.

Question 3

X suit la loi binomiale B(3 ; 0,5). Que vaut P(X = 2) ?

Réponse C. (32) × 0,5² × 0,5 = 3 × 0,125 = 0,375.

Exercice

On lance 4 fois une pièce équilibrée. X est le nombre de « Pile » obtenus. 1) Quelle est la loi de X ? 2) Calculer P(X = 2) et P(X ≥ 1). 3) Donner E(X).

Voir la correction

1) Ce sont 4 répétitions indépendantes d’une expérience à deux issues, avec « Pile » de probabilité 1/2 : X suit la loi B(4 ; 1/2). 2) P(X = 2) = 6 × (1/2)4 = 6/16 = 3/8. P(X ≥ 1) = 1 − P(X = 0) = 1 − 1/16 = 15/16. 3) E(X) = 4 × 1/2 = 2.
